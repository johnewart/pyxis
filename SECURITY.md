# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately. Do not open a public issue or pull request for them.

Use GitHub security advisories: on the repository page at https://github.com/johnewart/pyxis, open the **Security** tab and choose **Report a vulnerability**. This opens a private advisory that only you and the maintainers can see.

Include:

- the affected version or commit,
- a description of the problem and its impact,
- steps or a proof of concept to reproduce it.

You can expect an acknowledgement of your report, and we will keep you updated as the fix progresses. Once a fix is released we will publish the advisory and credit you if you want.

## Supported versions

Security fixes are made on the latest release and on the main branch.
